☁️ Penyimpanan Cloud (Utama)

Aplikasi ini kini tersambung ke Google Sheets sekolah. Selama Anda login, setiap perubahan data (tambah/edit/hapus) otomatis tersinkron ke sana dalam hitungan detik — jadi data Anda tetap aman walau berpindah perangkat/browser, asal login memakai akun yang sama. Aplikasi tetap bisa dipakai saat offline (tersimpan dulu di perangkat), lalu otomatis tersinkron begitu internet kembali tersambung.

☁️ Tersambung

Backup & Restore Manual (Tambahan)

Selain sinkron otomatis ke cloud di atas, Anda tetap bisa mengunduh salinan data sebagai file cadangan (.json) kapan saja — berguna untuk arsip pribadi atau memindahkan data secara manual.

⚠️ Pulihkan dari Backup akan langsung menimpa data Anda di CLOUD (bukan cuma di perangkat ini) dengan isi file backup tadi. Pastikan file yang dipilih memang yang terbaru/benar sebelum melanjutkan — tindakan ini tidak bisa dibatalkan.

📚 Mapel yang Saya Ampu

Centang mata pelajaran beserta kelas/jenjang yang Anda ajarkan. Ini penting kalau ada mapel yang sama diajar guru berbeda per jenjang (mis. Informatika kelas 7 oleh Anda, kelas 8-9 oleh guru lain) — supaya jadwal & dropdown yang muncul cuma yang relevan untuk Anda. Pengaturan ini ikut tersinkron kalau Anda login dari perangkat lain.

Zona Berbahaya

Tindakan berikut akan menghapus seluruh data (siswa, kelas, mapel, jurnal, nilai) secara permanen — termasuk salinannya di Google Sheets sekolah (cloud), bukan cuma di perangkat ini. Kalau Anda login sebagai Admin, ini juga akan menghapus data Kelas/Mapel/Siswa yang dipakai bersama seluruh guru lain. Gunakan hanya untuk mengembalikan aplikasi ke kondisi awal, misalnya untuk dipakai ulang di tahun ajaran baru.
